# DavinOS v3.0 🦆💻

A custom, lightweight desktop shell and operating system simulation built with Python and Pygame. Designed with a clean, macOS-inspired interface and a built-in DuckDuckGo privacy browser simulator.

## ✨ Features
* **Custom Desktop Environment:** Features a sleek blue wallpaper, top system menu bar, and clickable desktop shortcuts.
* **Built-in Browser Simulator:** Includes a custom-skinned DuckDuckGo privacy browser window with a working search input bar.
* **The "Fire Button" 🔥:** Click the flame icon in the browser to trigger an animation that instantly clears your search query and resets the view.
* **Standalone Linux App:** Compiled with PyInstaller and integrated into the ChromeOS Linux app launcher with a custom icon (`DavinOS_Icon.png`).

## 🛠️ How to Run

### Option 1: Run from Source (Python)
Make sure you have Python 3 and Pygame installed on your system:
```bash
pip install pygame
python3 davin_OSV2.py
```

### Option 2: Run the Linux Executable
If you downloaded the compiled Linux binary from the `dist` folder:
```bash
chmod +x davin_OSV2
./davin_OSV2
```
